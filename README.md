# rohit-chilhorkar.netlify.app

Portfolio of Rohit Chilhorkar, SRE and Platform Engineer. Static HTML and CSS, a few KB of JavaScript, no framework.

Two skins, switched with the bat button in the nav: **warm** (default) and **Night Shift**, a noir city with a searchlight, case files and a utility belt. `?theme=knight` or `?theme=warm` in the URL picks one. All Night Shift artwork is original and generated by `scripts/art.py`. In Night Shift, press B for bats.

## Layout

```
src/pages/        pages; the first line of each is a <!--meta {...}--> JSON header
src/partials/     nav, footer, icons, diagrams, artwork; included with {{> name}}
                  markup with class "w" shows only in warm, "k" only in Night Shift
src/styles/       base.css, warm.css, knight.css; the build scopes each skin to
                  <html data-skin="..."> and bundles them into assets/css/site.css
src/static/       copied as is: JS, images, favicons, resume PDF
resume/resume.tex resume source; CI compiles it into the PDF the site serves
scripts/build.py  the build (Python standard library only)
netlify.toml      build command, security headers, redirects
```

## Build and preview

```bash
python scripts/build.py
python -m http.server 8080 --directory dist
```

Netlify runs the same build on every push and stamps the commit into the footer.

## Update the resume

Edit `resume/resume.tex` and push to `main`. The `resume` workflow compiles it and commits the new PDF, and Netlify redeploys.
